## 🚀 Sobre o Projeto

**DevToolkit** é uma aplicação web Single Page Application (SPA) que reúne as ferramentas mais utilizadas no dia a dia de um desenvolvedor em um único lugar. O objetivo é eliminar a necessidade de buscar por "JSON Formatter" ou "Base64 Encoder" em sites repletos de anúncios e com interfaces ultrapassadas.

O projeto foi construído seguindo as tendências de design de 2026, utilizando **Glassmorphism**, **Bento Grids** e uma paleta de cores moderna em Dark Mode.

## ✨ Funcionalidades

O DevToolkit oferece mais de 30 ferramentas divididas em categorias:

### 🎨 CSS & UI
- **CSS Gradient Generator**: Crie gradientes complexos visualmente.
- **Glassmorphism Generator**: Gere o CSS para o efeito de vidro fosco.
- **Neumorphism Generator**: Crie elementos com Soft UI.
- **Box Shadow Generator**: Controle total sobre sombras CSS.
- **Animista**: Galeria de animações CSS prontas para uso.

### 🛠️ Formatação e Conversão
- **JSON Formatter**: Valide e formate JSONs complexos.
- **Base64 Encoder/Decoder**: Converta strings e arquivos.
- **URL Encoder/Decoder**: Codifique URLs para uso seguro.
- **JWT Decoder**: Inspecione tokens JWT sem enviar para o servidor.

### 🌐 Redes e Infra
- **DNS Checker**: Verifique a propagação de DNS.
- **My IP**: Descubra seu IP público e informações de localização.
- **Chmod Calculator**: Calcule permissões Linux octais/simbólicas.

### ⚡ Produtividade
- **Lorem Ipsum Generator**: Gere texto dummy customizado.
- **UUID Generator**: Crie identificadores únicos (v1, v4).
- **Regex Tester**: Teste suas expressões regulares em tempo real.

## 💻 Tech Stack

- **Frontend**: React 18
- **Linguagem**: TypeScript
- **Build Tool**: Vite
- **Estilização**: Styled Components
- **Roteamento**: React Router DOM (HashRouter)
- **SEO**: React Helmet Async
- **Ícones**: Lucide React

## 📦 Instalação

Clone o repositório e instale as dependências para rodar localmente:

```bash
# Clone o repositório
git clone https://github.com/Andre-Rodrigues-Dev-Web/ferramentas-para-devs.git

# Entre na pasta
cd ferramentas-para-devs/devtoolkit---o-canivete-suíço-do-desenvolvedor

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

Acesse `http://localhost:3000` no seu navegador.
